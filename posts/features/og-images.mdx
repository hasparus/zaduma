For a looping video card, put a 1200×630 mp4 in `public/` and point
`img.ogVideo` at it. The generated image stays its still frame.

```yaml
img:
  ogVideo: /content/my-post/og.mp4
```

It emits `og:video` for Discord, Telegram, and iMessage, and an X player card
that loops it in `/og/player/`.

You can test your social cards with

- Facebook Sharing Debugger — https://developers.facebook.com/tools/debug/
- Twitter Card Validator — https://cards-dev.twitter.com/validator
  - Image Preview doesn't work there anymore, so I'm using Bannerbear's Twitter
    Card Preview Tool
