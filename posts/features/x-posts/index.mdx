title: "X Posts"
tags: ["markdown"]
---

Put a link to an X post in its own paragraph, and the post shows up as a
picture:

https://x.com/jack/status/20

[xeet](https://xeet-rs.vercel.app) draws it at build time, with X's own fonts
and layout. There is no iframe and no script from X, so the page stays fast and
private. The picture has light and dark versions, and a narrower one for phones.
It links to the post, and its alt text holds the post's text.

The first build fetches the post from x.com and saves it as
`xeets/<post id>.json`. Commit that file. Later builds read it and don't touch
the network, so the picture doesn't change when the like count does. To fetch
the post again, delete its file.

If a build can't reach x.com, write the file by hand. Only `text` is required:

```json
{
  "text": "just setting up my twttr",
  "author": { "name": "jack", "handle": "jack", "verified": "blue" }
}
```

A link inside a sentence, like [this one](https://x.com/jack/status/20), stays a
link. Only `.mdx` posts get pictures.
